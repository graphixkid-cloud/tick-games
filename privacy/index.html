Tick Games Privacy Policy

Last updated: November 27, 2026

The short version: Tick Games collects no data. Nothing your child does in the games leaves the watch.

Tick Games is a set of learning games for Apple Watch, made for children ages 6 to 11 by Gama Studio LLC.

What we collect

Nothing. Tick Games does not collect, store or share any personal information.

  • It has no accounts or sign-ins.
  • It shows no advertising.
  • It has no analytics or tracking.
  • It makes no network connections.

What stays on the watch

Game progress, such as stars and the levels reached, is saved only on the Apple Watch. It is never sent to us or anyone else. Deleting the app deletes that progress.

Links for grown-ups

The iPhone app links to our website behind a parental gate, so only a grown-up can follow it.

Children’s privacy

Because Tick Games collects no information, it collects none from children. We never ask a child for a name, email, location or any other personal detail.

This website

This page is hosted on GitHub Pages. GitHub may record technical details such as IP addresses in its server logs. See GitHub’s privacy statement for how it handles that data.

Changes to this policy

If this policy ever changes, we’ll update this page and the date at the top.
